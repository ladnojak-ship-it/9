# Minecraft в GTA V — passthrough-мод

Настоящий Minecraft Java 26.3 работает параллельно с GTA V (Legacy, режим истории)
и рисуется **внутри** кадра GTA. Камера GTA управляет камерой Minecraft, земля GTA
становится невидимым полом в Minecraft, а картинка Minecraft (цвет + глубина)
вставляется в кадр GTA с depth-тестом против буфера глубины GTA — дома и столбы
Лос-Сантоса закрывают то, что находится за ними, и наоборот.

Что происходит в Minecraft — происходит и в GTA:

- поставленные блоки становятся невидимыми препятствиями для пешеходов и машин;
- взрывы TNT и криперов — это взрывы GTA;
- фейерверки из арбалета — ракеты GTA, попадания стрел по людям и машинам — пули;
- взмах меча швыряет людей и отбрасывает машины;
- жемчуг эндера телепортирует игрока GTA;
- элитры — полёт над Лос-Сантосом с погонной камерой GTA;
- мобы Minecraft дерутся с полицией GTA;
- портал в Нижний мир меняет мир вокруг на незеровый, небо GTA краснеет.

> **Только Story Mode. Никогда GTA Online.** Мод работает при выключенном
> BattlEye (`-nobattleye`), что и не даёт зайти в Online. ScriptHookV закрывает
> игру, если она всё же пытается уйти в сеть.

## Скачать готовую сборку

Собирается автоматически в GitHub Actions — ничего ставить на свой компьютер не
нужно (ни Visual Studio, ни JDK).

1. Откройте вкладку **Actions** → последний запуск `build` (зелёная галочка).
2. Внизу, в разделе **Artifacts**, скачайте `MinecraftInGTA.zip`.
   Там внутри:
   - `GTA\` — что копируется в папку GTA V;
   - `MINECRAFT\mods\` — jar мода и Fabric API;
   - `install.bat` / `install.ps1` — установщик;
   - `README.txt` — короткая инструкция.
3. Распакуйте куда угодно и запустите `install.bat`.
   Он сам найдёт GTA V (Steam) и Minecraft; пути можно задать вручную:

   ```bat
   install.bat -GtaDir "<папка с GTA5.exe>" -McDir "<папка minecraft вашего профиля>"
   ```

   Все заменённые файлы сохраняются в `GTA\_passthrough_backup_<дата>\`.
   Установщик не трогает загрузчики других модов (OpenIV и т.п.) — если
   `dinput8.dll` или `ReShade64.asi` оказались чужими, он попросит `-Force`.

Удаление: `install.bat -Remove` — убирает только файлы этого мода.

## Если блоки «плывут» при быстром движении

Компоситор каждый кадр перепроецирует кадр Minecraft на текущую камеру GTA. Если
Minecraft рисует медленнее GTA (низкий FPS), при резком движении камера уходит
сильнее, чем позволяет репроекция, и блоки смирятся. Решение — поднять FPS
Minecraft: в сборку входит **Sodium** (последний стабильный под MC 26.3),
который ставится отдельным флагом:

```bat
install.bat -WithSodium
```

Пасc-through работает и без него. Убрать Sodium: `install.bat -Remove` или просто
удалить `sodium-fabric-*.jar` из папки `mods`. Если после Sodium картинка
сломается совсем (Sodium меняет конвейер отрисовки Minecraft) — просто удалите
его jar, мод вернётся к прежнему поведению.

## Запуск

1. Запустите Minecraft в профиле FreesmLauncher (Fabric) и **оставьте окно
   открытым** — свёрнутое окно рисует медленно.
2. Запустите GTA V из Steam и выберите **Story Mode** самостоятельно.
3. В игре появится `Minecraft passthrough connected` — мод выровняет землю и
   начнёт слать её в Minecraft.
4. **F7** — вкл/выкл накладку, **F8** — выровнять землю заново.

Мод сам создаст пустый креативный мир `passthrough`, выдаст хотбар (жемчуг
эндера, меч, арбалет, лук, TNT, кресало, яйца криперов, блоки травы, фейерверки)
и настроит параметры (без облаков, 120 fps, работает не в фокусе). Ваши миры и
настройки Minecraft не затрагиваются — у мода свой профиль.

## Управление

| Клавиша | Действие |
|---|---|
| F7 | вкл/выкл passthrough |
| F8 | выровнять землю Minecraft под игрока |
| ЛКМ | атака Minecraft: ломать блоки, рубить мечом |
| ПКМ | действие: ставить блоки, поджигать TNT, стрелять, бросать жемчуг, разгон фейерверком |
| колесо, 1–9 | хотбар Minecraft |
| Space | взлёт на элитрах (когда включён режим полёта) |

Ходьба, вождение и камера — как в GTA; Minecraft повторяет их камеру.

## Что внутри

```
GTA V (ScriptHookV .asi + ReShade add-on)          Minecraft 26.3 + Fabric
  script.cpp      --WebSocket 127.0.0.1:25599-->    HostLink:  камера, земля, ввод
                  <---------------------------------           взрывы, попадания
  compositor.cpp  <-- shared memory ----------------  FrameExporter: цвет+глубина, рука/HUD
  MCPassthrough.fx: depth-тест, репроекция, свет
```

- Координаты: 1 метр GTA = 1 блок; GTA (x, y, z) → MC (x, z + yOffset, −y);
  yaw = 180 − heading, pitch = −pitch.
- Каждый кадр GTA присылает камеру и землю под игроком (зонды → barrier-блоки),
  каждый кадр Minecraft отдаёт цвет + глубину; ReShade-эффект вставляет картинку
  против буфера глубины GTA, перепроецируя её с позы past-frame на текущую камеру
  (это скрывает задержку линка).
- Обратный канал: поставленные/сломанные блоки → невидимые пропы GTA; взрывы,
  снаряды, удары меча, жемчуги, мобы и ни жаркие блоки → события GTA.

Детали реализации и грабли — в исходниках: `mc/` (Fabric-мод, Java 25),
`gta/src/` (плагин), `gta/shaders/MCPassthrough.fx`.

## Сборка

Всё собирается в GitHub Actions (`.github/workflows/build.yml`):

- `mc-mod` — Gradle/Loom (Temurin JDK 25) на ubuntu-latest, плюс Fabric API
  той же версии Minecraft с Modrinth;
- `gta` — windows-latest: `gta/fetch_deps.sh` качает ScriptHookV SDK и ReShade,
  `gta/build.bat` собирает `MCPassthrough.asi` компилятором MSVC (он уже есть на
  образе runner'а), `scripts/package.ps1` пакует `MinecraftInGTA.zip`.

Локально то же самое: `cd mc && ./gradlew build` (нужен JDK 25) и
`gta/fetch_deps.sh` + `gta/build.bat` (нужен MSVC). Без игр: `host/fakehost.py`
(питоном) проверяет совмещение кадров, `gta/tests/fakegta.cpp` — весь GTA-пол
кроме нативов.

## Файлы репозитория

| путь | что это |
|---|---|
| `mc/` | Fabric-мод: линк, экспорт кадров, синхр мира, мобы, Нижний мир, миксины |
| `gta/src/` | `script.cpp` (скрипт ScriptHookV), `compositor.cpp` (add-on), `ws.cpp`, `natives.h` |
| `gta/shaders/` | эффект ReShade `MCPassthrough.fx` |
| `scripts/` | `package.ps1` (сборка пакета), `fetch_fabric_api.py` (Fabric API из Modrinth) |
| `install.ps1`, `install.bat` | установщик/удаление на машине игрока |
| `host/`, `video/` | тесты без GTA, директор и нарезка видео |

## Безопасность и лицензии

- Только одиночная игра/свои серверы. Никаких читов для онлайна.
- ScriptHookV (Alexander Blade) и ReShade (crosire) **не перераспространяются
  в этом репозитории** — они скачиваются со своих сайтов во время сборки.
  Поэтому и артефакт `MinecraftInGTA.zip` — для личного использования.
- Никаких файлов Minecraft, GTA и распакованных ассетов в репозитории нет.
- Сделано с помощью ИИ-агента (OpenCode). Фича-паритет с примером
  `universal-modder/examples/minecraft-gta5-passthrough`.
